# Region 3 Attributes

## Attribute List

### `DOM_TYPE`
- Dominance class from species/genus/mixed evergreen-deciduous rules.

### `DCC1`
- Primary dominant canopy component label (species/genus/mix class).

### `XDCC1`
- Corrected canopy percent represented by `DCC1`.

### `DCC2`
- Secondary dominant canopy component label.

### `XDCC2`
- Corrected canopy percent represented by `DCC2`.

### `CAN_SIZCL`
- General canopy size class from dominant DBH canopy bins.

### `CAN_SZTMB`
- Timberland-specific canopy size class using timberland bin rules.

### `CAN_SZWDL`
- Woodland-specific canopy size class using woodland bin rules.

### `BA_STORY`
- One-, two-, or three-story class from BA concentration across DBH windows.

## Notes

- Region 3 also includes all attributes in `core_attributes.md`.
