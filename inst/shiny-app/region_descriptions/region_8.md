# Region 8 Attributes (Custom North Carolina Classification)
## Not official USFS R8 Classification 

## Attribute List

### `SSDOMSPP`
- Dominance code from species composition in advanced regeneration (`SSTPA`).

### `NMDOMSPP`
- Dominance code from species composition in non-merchantable BA pool.

### `PWDOMSPP`
- Dominance code from species composition in pulpwood BA pool.

### `STDOMSPP`
- Dominance code from species composition in sawtimber BA pool.

### `DOMTYPE`
- Stand-level species dominance code from total stand BA.

### `SSSIZE`
- TPA-weighted height for advanced regeneration pool.

### `SSTPA`
- Tree density for advanced regeneration pool.

### `NMBA`
- BA in non-merchantable tree pool.

### `NMSIZE`
- BA-weighted DBH in non-merchantable pool.

### `PWBA`
- BA in pulpwood tree pool.

### `PWSIZE`
- BA-weighted DBH in pulpwood pool.

### `STBA`
- BA in sawtimber tree pool.

### `STSIZE`
- BA-weighted DBH in sawtimber pool.

### `VEGCLASS`
- Combined size-density code (for example `3C`) from BA/TPA thresholds and pool dominance.

## Notes

- Region 8 also includes all attributes in `core_attributes.md`.
