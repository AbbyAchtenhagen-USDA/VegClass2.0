# Region 2 Attributes

## Attribute List

### `DOM_TYPE_R2`
- Top dominant species code combination from corrected canopy ranking.

### `DOM_TYPE_R2_CC1`
- Corrected canopy percent of first-ranked dominant species.

### `DOM_TYPE_R2_CC2`
- Corrected canopy percent of second-ranked dominant species.

### `DOM_TYPE_R2_CC3`
- Corrected canopy percent of third-ranked dominant species.

### `COVERTYPE_R2`
- Cover type from R2 SAF/SRM mapping plus grouped-species overrides.

### `TREE_SIZE_CLASS_R2`
- Dominant canopy size class from E/S/M/L/V canopy bins.

### `CROWN_CLASS_R2`
- Crown class based on stand canopy cover thresholds.

### `HSS1_4C`
- Stage class from canopy cover and size bins (optional module).

### `HSS1_5`
- Extended stage class including old-growth decision path (optional module).

## Notes

- Region 2 also includes all attributes in `core_attributes.md`.
- `HSS1_4C` and `HSS1_5` appear when the `Add HSS` option is enabled.
